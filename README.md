# Client Cheat Quest · 20 关客户端修改训练营

一个纯前端（原生 HTML/CSS/JS，零依赖）的教学小游戏：**正常玩永远过不去，必须靠修改客户端才能通关**。
用来练习四类基础手法，再平滑过渡到编码加密存档、绕过客户端校验、反混淆等进阶手法。

## 怎么玩

直接用浏览器打开 `index.html` 即可（无需服务器、无需安装任何东西）。

- 右侧 **CE 式内存扫描器**：首次扫描 → 变动后再次扫描 / 增加了·减少了·未变化 → 锁定地址 → 改值 / 冻结。
- 右侧 **内置控制台**（等同 F12 Console）：直接改全局变量、调用隐藏函数、Hook 判定函数。
- 场景里的存档框：导出/查看原始存档，解码或改值后写回。
- 每关有「拿提示」，提示分三级，最后一级直接给做法。

进度自动存在浏览器 localStorage。

## 20 关梯度（由易到难）

| 关 | 名称 | 手法 |
|----|------|------|
| 1 | 源码里的钥匙 | 读 HTML 源码找后门密码 |
| 2 | 控制台里的钱包 | 控制台改全局变量 gold |
| 3 | 找到你的血量 | CE 固定值扫描（练习+实战） |
| 4 | 会变动的金币 | CE 动态值再次扫描 |
| 5 | 明文存档 | 篡改 localStorage 明文 JSON |
| 6 | 冻结你的血条 | CE 冻结数值（练习+实战） |
| 7 | 藏起来的调试函数 | 控制台调用隐藏函数 |
| 8 | 注释里的暗号 | 读源码注释找暗号 |
| 9 | Base64 存档 | 解码→改值→编码写回 |
| 10 | 不知道数值怎么扫 | CE 未知初始值（全部列出→增加了） |
| 11 | 被拒绝的按钮 | Hook 判定函数 canPass |
| 12 | 异或加密存档 | XOR+Base64 解密改值 |
| 13 | 真假地址陷阱 | 辨别会回弹的假地址 |
| 14 | 改名后的开关 | 轻度混淆源码找开关 |
| 15 | 藏在深处的锁 | 改嵌套对象 player.quests[0].locked |
| 16 | 客户端说了算 | 绕过客户端校验 verify |
| 17 | 会搬家的地址 | 地址漂移，重新扫描（练习+实战） |
| 18 | 带校验和的加密存档 | Base64+XOR+CRC，改完重算校验和 |
| 19 | 读懂那团乱码 | 反混淆后 Hook 判定 |
| 20 | 终局·三合一 | CE 改值 + 改存档 + 绕过守门 |

> 带「练习小关 → 实战小关」的关卡：3、6、10、17、20。

## 目录结构

```
client-cheat-quest/
├── index.html          # 入口，直接打开
├── css/style.css
├── js/
│   ├── engine.js       # 伪内存表 / CE扫描 / 控制台 / 编码辅助
│   ├── levels.js       # 20 关定义
│   └── main.js         # 关卡调度 / 扫描面板 / 判定
└── test/selftest.js    # 无头自测（jsdom）
```

## 本地自测

```bash
npm install
node test/selftest.js
```

## 说明

- 这是教学模拟：CE 扫描器是游戏内仿真，不读写任何真实进程内存。
- 所有「作弊」只作用于本游戏页面本身，请勿用于破坏他人软件或在线服务。
